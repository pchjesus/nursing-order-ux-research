# 간호처방 UI/UX MVP 요구사항 — 방향 승인 / 임상 검증 전
작성: 2026-10-10 · 단계: 설계 v0.2 · 코딩 전

## 1. 확정된 기획 방향
- **DEC-001 A:** 간호중재·간호행위(`ACT`)를 1차 대상으로 사용한다. `FOLLOW`(타 직종 처방 연계 수행) 및 `MAT`(물품)은 원본 자료에서 구별·보존하며, 같은 처방으로 합치지 않는다.
- **DEC-002 C:** 초기 MVP는 처방 전 **검색·선택**과 처방 후 **수행·기록 조회**를 연결한다. 실제 처방 발행·간호 수행·서명 기능을 의미하지 않는다.
- **DEC-003 C:** 업무 단계별 상위 정보 구조와 임상 목적별 하위 카테고리를 결합한 **혼합형**을 사용한다.
- 사용자가 승인한 것은 방향이다. 화면 버튼, 실제 등록 동작, 반복 처방 그룹화 세칙, 상태 전이·권한은 **미확정**이다.

## 2. 자료 및 MVP 경계
- 기존 합성 후보 총 **315건(24개 후보 카테고리)**: `ACT 214 / FOLLOW 42 / MAT 59`. 이 목록은 실제 병원 처방 목록 또는 공식 NIC 항목이 아님.
- MVP에 사용할 **ACT 후보 20~40개는 이후 선정·검수**한다. `FOLLOW`/`MAT`는 구분 테스트와 참고 자료로 사용하며, 기본 ACT 처방 집계에 포함하지 않는다.
- 가상 환자, 가상 역할, `SIM-` 처방 후보 및 가상 처방 인스턴스만 사용한다.
- nU 연동, 실환자 자료·병원 내부 코드, 실제 처방/간호기록 입력, 의료적 판단·임상 자동 추천은 제외한다.

## 3. 우선순위 및 검증 상태
- P0: 원본 신원, 환자 분리, 오선택 방지, 상태/집계 무결성
- P1: 검색, 분류, 전후 화면 연결 및 필수 조회
- P2: 개인화/즐겨찾기 등 편의 기능
- **[승인]** 사용자 기획 방향, **[제안]** UX 요구 및 후보 규칙, **[미확인]** 임상 업무·권한·기록 규정, **[보류]** 구체적 UX 선택.

## 5. 객체 및 계산 의미 — 개념 모델, 실제 DB 아님
- `catalog_item`: 후보 코드/명칭/유형/동의어/분류/검증 상태. **존재 자체가 처방 가능성을 증명하지 않음**.
- `order_definition`: 가상 처방 정의. 후보 목록과 동일 객체로 간주하지 않음.
- `order_instance`: 가상 환자에게 등록되어 있다고 **가정하는 개별 처방**. 고유 ID/조건/상태/시각 보존.
- `execution_event`: 개별 수행 사건. 예정 건수와 실제 수행 건수는 분리.
- `documentation_record`: 기록 ID·작성/수정/서명 이력. 수행 사건과 1:1로 고정하지 않음.
- `execution_document_link`: 수행–기록 연결. 0:다수 또는 다수:다수 관계 가능.
- **처방 건수** = 개별 처방 인스턴스 수. **수행 사건 건수** = 개별 수행 이벤트 수. **기록 건수** = 고유 기록 수(연결로 인한 중복 집계 금지).
- 화면 그룹화는 같은 가상 환자·원본 정의·**필수 임상 조건이 확인된 경우**만 검토한다. 단순 명칭 동일만으로 그룹 동등성 판단 금지. 상태/조건 불분명 시 별개로 보여준다.
- `MAT` 소모품은 행위·처방·수행 횟수 계산에 포함하지 않음.

## 6. 실무 검증 전제 및 미확인 질문
1. 실제 기관의 '간호처방'이 독립 간호행위·의료진 처방 연계·수가 입력 중 무엇을 뜻하는가?
2. 간호사의 직접 등록/수행/기록 권한 및 병동별 예외는 무엇인가?
3. 유사 드레싱 등 항목을 구별하는 실제 부위·방법·목적·빈도·적응증은 무엇인가?
4. 반복 처방의 예정·실제·중단·보류·취소 상태를 어떻게 해석·계산하는가?
5. 수행 1건과 기록 1건의 관계는 항상 1:1인가? 지연 기록과 정정은 어떤 규칙을 따르는가?
6. 사용자의 검색 전략·업무 단계 구분이 실제 간호사의 일상 업무와 일치하는가?
7. 실제 병원 화면·용어를 적법하게 검토할 수 있는 범위는 어디까지인가?

## 7. MVP 개발 진입 조건
- ACT 20~40개 후보의 의미·동의어·구별 속성 검토.
- 처방 전후 모의 시나리오·그룹화 반례·기록 이력 사례에 대한 안전성 검토.
- 가상 선택 후 동작, 상태 표현, 그룹화 조건 등 핵심 보류 선택에 대한 사용자 승인.
- 현직 간호사 또는 간호정보학 전문 검토의 결과/한계를 기록.
- **실제 UI와 코드 개발은 별도 단계**. 현재는 계획·가상 시나리오·수용 기준만 문서화한다.
