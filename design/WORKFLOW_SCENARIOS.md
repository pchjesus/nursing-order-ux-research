# 간호처방 전후 연결 업무 시나리오 — 모의 검증용 v0.2
작성: 2026-10-10 · **임상 업무 검증 전 / 구현 전 / 실제 nU 화면 아님**

## 1. 사용자 및 데이터 맥락
- **U1:** 일반병동 간호사 역할을 가정한 모의 사용자. 실제 수행·등록 권한을 가정하지 않음.
- **P-A, P-B:** 서로 다른 합성 환자. 환자 이름·등록번호 등 실제 개인정보 없음.
- **자료:** `data/CATALOG.*`의 원본 후보 코드를 유지. 아래 가상 처방 ID `O-A1`, 수행 ID `E1`, 기록 ID `D1` 등은 모두 설계 사례에만 사용.
- **상위 업무 흐름 [승인]:** '간호활동 찾기'(검색/선택) ↔ '수행·기록 현황'(조회); 내부 임상 카테고리 탐색. **화면명·실제 버튼 구성은 제안**.

## 2. 기준 업무 흐름
### 처방 전
가상 환자/업무 맥락 확인 → 전체 검색 또는 임상 목적 카테고리 탐색 → 유사 결과 차이 확인 → 항목별 상세 조건·검증 상태 확인 → **가상 초안/후속 조회(동작 보류)**.

### 처방 후
같은 합성 환자 선택 → 개별 처방 또는 반복 그룹 요약 조회 → 처방·수행 사건·기록 건수 확인 → 개별 ID·상태·시각·정정 이력 펼쳐보기.

이 흐름은 처방 조회·기록 관계의 **시연을 위한 설계 가설**이며 실제로 의료진이 처방하거나 간호사가 수행·기록하는 업무 절차를 재현하지 않는다.

## 3. 핵심 시나리오 (수행 전/후 + 예외)
| ID | 시작·사용자 과제 | 기존 합성 항목/사건 예시 | 기대 결과 · 확인 사항 |
|---|---|---|---|
| S01 | P-A에서 '드레싱' 검색, 적절한 후보 식별 | `SIM-ACT-0052` 일반 창상 드레싱 관리, `0053` 멸균 창상 드레싱 관리, `0054` 수술부위 드레싱 관리, `0043` 중심정맥관 삽입부 드레싱 관리 | 원본명·가상코드·분류, 검증된 구별 속성 표시. 실제 수행 조건 미검증은 '확인 필요'. 검색만으로 등록되지 않음 |
| S02 | 검색 결과 선택 후, 같은 정의의 처방 후 이력 조회 | `SIM-ACT-0053` 선택 / 가상 처방 `O-A1` | 목록 후보와 실제 등록되었다고 가정한 개별 처방을 분리. 추적 가능한 정의 코드·개별 ID 제공. 선택 이후 정확한 동작은 보류 |
| S03 | 같은 가상 코드의 별도 처방 2건 구분 | `O-A1`, `O-A2`, 조건/시각이 다른 P-A 처방 | 요약은 처방 2건, 상세는 각각 ID·조건·시각 노출. 단순 명칭만으로 원본을 합치지 않음 |
| S04 | 반복 수행 3건과 기록 2건 조회 | 가상 `E1,E2,E3` 및 `D1,D2`, 연결관계 별도 | '수행 3 / 기록 2'로 표기하되, 3-2=미기록 1건이라 단정 금지. 기록 연결 확인 가능 |
| S05 | 보류·취소·연기 처방과 미수행 구별 | 여러 가상 처방 상태와 예정·실제 사건 | 취소/보류를 미수행 오류로 표시하지 않음. 상태 전이 및 개별 권한 미확정임을 명시 |
| S06 | '수액 세트' 또는 '수혈 전 확인'을 검색 | `SIM-MAT-0001` 일반 수액 주입세트 / `SIM-FOLLOW-0013` 수혈 전 환자 확인 | `MAT/FOLLOW`는 ACT와 다른 종류. 기본 ACT 처방과 자동 결합·집계 금지. 참고 결과 노출 방식은 보류 |
| S07 | 'BST' 약어 검색 또는 결과 없는 질의 | 검수 전 검색 동의어 | 약어가 여러 뜻에 해당하면 자동 선택 금지. 현재 적용된 범위·필터/검색 결과 없음 안내 |
| S08 | P-A에서 P-B로 환자 전환 후 이력 보기 | 별도 환자 식별 ID | P-A의 처방·수행·기록이 P-B 화면에 남지 않음 |
| S09 | 한 수행/기록의 정정 이력 확인 | `E1`, `D1`의 정정 버전 | 원본 신원·기록 시각·수정 흔적 보존. 최신값으로 무조건 덮어쓰기 금지 |
| S10 | 실제 권한/기록 의무가 확인되지 않은 활동 조회 | 일부 `ACT` 후보, 권한 '미확인' | 실제로 처방 가능·수행 승인·공식 서명 완료라고 표현하지 않음 |

## 4. 사용성 평가 후보
- 과제: 특정 드레싱을 정확하게 찾기 / 간호활동과 물품 구별 / 동일 코드 반복 처방 ID 찾기 / 수행·기록 건수 구분 / 취소·보류 상태 해석.
- 비교 화면: **동일 합성 데이터의 기본 목록형 화면** 대 **혼합형 화면**. 실제 nU와 직접 비교했다고 주장하지 않음.
- 지표: 정확 선택률, 오선택 유형, 탐색 소요시간, 클릭·탭 이동 수, 상태/횟수 해석 정확도, 사용성·인지부하 설문. 기준값과 참가자 수는 조사 설계 이후.
- 반례: 동명이 다른 조건, 환자 변경, 수행–기록 다대다, 정정 이력, 약어 충돌, 검색 결과 없음, 권한 미확인.

## 5. 업무 검증 시 확인할 항목
- 실제 간호사 등록·수행·기록 책임과 예외, 검색 가능한 간호처방 범위, 단계별 업무 순서.
- 각 `ACT` 후보의 실제 의미, 드레싱 등의 구별 속성, 임상적인 '같음/유사함' 기준.
- 반복 예정·완료·연기·취소의 상태 정의, 수행–기록 연결 방식, 기록 완료의 판단 기준.
- 실제 nU 화면/코드가 검증되지 않았다는 점을 유지하면서 모의 환경에서 평가할 과제의 타당성.
