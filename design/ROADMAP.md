# 단계별 개발 로드맵 (제안)

| 단계 | 목표 | 작업 | 근거 | 임상·기술 위험 | 검증 | 다음 단계 진입 조건 |
|---|---|---|---|---|---|---|
| 0. 분류 대상 탐색 | 폭넓은 후보 발굴 | 공식 문헌·공개 목차·임상 지침 조사; 가상 315개 분류 작성 | NIC, ICNP, Perry 외, WHO, CDC, HIRA | 실제 처방 목록으로 오인 | 출처별 용도 표시, 가상코드·유형 검수 | 목록과 제한사항 문서화 (달성) |
| 1. 용어·업무 검증 | 실제 간호처방 범위 확정 | 현직 간호사/간호정보학 전문가와 `ACT/FOLLOW/MAT` 항목 검토; 실제 권한 질문 작성 | 실제 병동 업무·기관 지침 | 학생의 관찰을 실무로 과잉 일반화 | 검증 회의록, 모순/미확인 기록 | MVP 항목 20~40개 승인 및 권한·의미 확인 |
| 2. 데이터 모델·UX 대안 | 검색부터 기록까지 연결 | 정의/개별 처방/수행/기록 모델과 상태·그룹화 규칙 비교 | SAFER, 간호정보학·인간공학 문헌 | 데이터 손실, 오그룹화, 상태 착오 | 합성 반례, 종이 프로토타입 과제 수행 | 주요 UX·기획 의사결정 승인 |
| 3. MVP 구현 | 합성 데이터 기반 동작 | 검색, 유사 결과 구별, 초안 상세 확인, 처방 후 이력 조회 | 검증된 요구사항 | 회귀·상태·데이터 정합성 | 기능/예외/회귀 테스트 | 지정 테스트 케이스 통과 |
| 4. 모의 사용성 평가 | 정확성·효율 측정 | 비교과제, 오선택률, 과제 완료 시간, 수행/기록 건수 해석, 면담 | 사용성 방법론 | 작은 표본과 실제 업무 차이 | 정량·정성 분석, 한계 명시 | 유의미한 개선 여부 보고 및 중대한 오류 없음 |
| 5. 선택적 확장 | 현장 검증을 통한 확장 | 즐겨찾기, 고급 필터, 기록 상태, 보안·감사 이력 검토 | 실제 필요·검증 결과 | 확장 과잉, 권한 오류, 기능 충돌 | 단계별 회귀·권한·보안 테스트 | 별도 기관 승인·임상 검증 전까지 임상 미사용 |

## 첫 MVP 범위
- 합성 항목 **20~40개** 사용(315개 후보 목록에서 유사 명칭, 물품·행위 혼동 등 스트레스 사례를 선택)
- 명칭/검색 동의어/가상코드 검색과 필터
- 유사 후보의 핵심 구별 정보 및 선택 전 상세 화면
- 합성 개별 처방과 수행/기록 현황(생성·수정 실제 업무 기능은 넣지 않아도 됨)
- 건수의 의미와 그룹화 여부 확인

## 명시적 범위 밖
병원 nU 연동, 실제 병원 처방코드, 실환자 데이터, 의료진/간호사 권한 자동판단, 공식 기록, AI의 임상 처방 추천.
