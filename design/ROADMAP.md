## 첫 MVP 범위
- 합성 `ACT` 항목 **20~40개** 선정 예정(기존 315건 전체 유지. `FOLLOW`/`MAT`는 유형 혼동 테스트용 별도 참고자료로 보존)
- 명칭/검색 동의어/가상코드 검색과 필터
- 유사 후보의 핵심 구별 정보 및 선택 전 상세 화면
- 합성 개별 처방과 수행/기록 현황(생성·수정 실제 업무 기능은 넣지 않아도 됨)
- 건수의 의미와 그룹화 여부 확인

## 명시적 범위 밖
병원 nU 연동, 실제 병원 처방코드, 실환자 데이터, 의료진/간호사 권한 자동판단, 공식 기록, AI의 임상 처방 추천.

## A–C–C 확정에 따른 단계 게이트 (2026-10-10)
- **확정:** 간호중재·간호행위 중심(A) / 처방 전후 연결형(C) / 혼합 카테고리(C).
- **현재:** 0단계 합성 후보·자료 준비 완료, 1단계 업무 검증 및 요구사항 설계 진행. UI 구현·임상 검증·사용성 평가 미수행.
- **1→2 진입:** 실제 업무의 간호처방 범위, 권한·기록 책임 검토 계획 및 ACT 20~40개 선정 기준 마련. 미확인 사실 별도 기록.
- **2→3 진입:** [REQUIREMENTS](REQUIREMENTS.md) R01~R15, [WORKFLOW_SCENARIOS](WORKFLOW_SCENARIOS.md) S01~S10, 검증 반례·상태 규칙 정합성 점검; OPEN-01~06 중 MVP에 필요한 UX 선택 승인.
- **3단계 착수 전:** 비교 가능한 정적 와이어프레임과 합성 이력 데이터 준비, 위험·회귀 범위 검토. 실제 코딩 착수는 후속 명시적 요청 이후.

## 기능형 MVP v0.2 진행 상태 (2026-10-10)
- 사용자의 후속 요구에 따라, 위 단계 1·2의 **임상 유효성 검증 완료를 기다리지 않고** 가상 데이터로 기능 프로토타입을 제작했다. 이는 **교육/시연용 기술 검증**이며 위 표의 임상 업무 검증·환자안전 검증 진입 조건을 충족했다는 뜻이 아니다.
- 현재 제공: ACT 38개, 환자 4명, 가상 처방 16건, 로그인 근무조/현재 확인자, 임시저장→PIN 재인증→가상 확정, 수행·기록 이력.
- 남은 핵심 과제: 임상 전문가 검토, 실제 역할/권한 정의, 반복 처방 및 그룹화 규칙, 독립 2인 확인 정책 필요성, 서버 인증/공유 기록 여부, 실제 브라우저·사용자 테스트, UI 반복 개선.
- 기술 검증 결과: `docs/TEST_REPORT.md`. 현재 UI 디자인은 고정하지 않음.
