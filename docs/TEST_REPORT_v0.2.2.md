## 시험 환경과 제한
- Node.js v22 및 Linux Chromium/Playwright.
- 테스트 실행 환경의 브라우저 정책이 `http://127.0.0.1`과 `file://` 페이지 탐색을 차단해서 **실제 HTTP URL로 페이지를 열어 검사하지 못함**. 대신 Chromium에 HTML/CSS/JS를 주입하고 localStorage를 메모리 대체 객체로 만들어 클릭 경로를 검증.
- 따라서 **실제 브라우저 주소에서의 로딩·새로고침 후 localStorage 지속 저장·모바일 시각 구성**은 이번 검증에 포함되지 않음. 기존 `app/domain.js`의 JSON 왕복 저장 테스트는 통과.
- 학교 자료의 간호 임상 적절성, 처방권한, 실제 nU 유사성, 실제 약물 투여 안전성을 시험하지 않음.
- 사용자는 MVP 기능이 더 안정화되면 직접 테스트하기로 했으며 **사용자 사용성 실험 미실시**.
