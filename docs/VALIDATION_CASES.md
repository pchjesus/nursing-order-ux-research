# 초기 안전·사용성 검증 사례 (아직 테스트 실행 전)

| ID | 테스트 시나리오 | 기대하는 안전 기준 |
|---|---|---|
| T01 | '드레싱' 검색 | 여러 드레싱 후보와 차이·유형을 표시, 자동으로 확정하지 않음 |
| T02 | '수액세트' 검색 | 소모품·기구는 간호행위가 아닌 별도 유형으로 표시 |
| T03 | 'BST' 동의어 검색 | 둘 이상의 관련 후보에 연결되는 경우 잘못된 자동선택이 없음 |
| T04 | 같은 가상 처방코드의 개별 처방 2건 | 화면에서 묶여도 개별 ID·시각·조건은 접근 가능 |
| T05 | 수행 사건 3건, 관련 기록 2건 | 단순 차감으로 기록 누락을 단정하지 않음 |
| T06 | 취소·보류된 반복 처방 | 예정/수행/기록 의미를 구별하고 누락으로 섣불리 분류하지 않음 |
| T07 | 유사명칭이나 조건·부위가 다른 처방 | 이름만 같다고 데이터 병합하지 않음 |
| T08 | 간호 수행 권한 정보 누락 | 시스템이 임의로 허용·승인했다고 표시하지 않음 |
| T09 | 처방 종류가 아닌 물품만 존재 | 물품을 수행 완료·처방 완료로 집계하지 않음 |
| T10 | 수정·정정된 수행/기록 | 원본 ID와 수정 이력을 보존할 수 있는 설계 |
| T11 | 합성 환자 2명의 기록 검색 | 다른 환자의 처방이나 수행 이력이 섞이지 않음 |
| T12 | 검색 결과 없음 | 전체 카테고리 누락을 뜻하는 것으로 잘못 표현하지 않음; 명확한 결과 안내 |

**상태:** `설계 완료 / 실행 전`. 실제 시스템과 비교하거나 임상적 환자안전 성과를 검증한 결과가 아님.
