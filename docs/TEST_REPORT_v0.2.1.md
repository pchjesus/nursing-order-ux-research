## 주요 확인
- 기본 상태는 기존 **개별 목록**이며 체크박스로 언제든 돌아갈 수 있음.
- 같은 **가상 환자 + 같은 SIM-ACT 코드**에 속하는 항목만 요약하되, 개별 주문 ID·시각·메모·상태·수행 및 기록 객체는 병합하지 않음.
- 처방건수/수행사건건수/기록건수를 별도로 표시. 단순 감산으로 '기록 누락'을 판단하지 않음.
- 환자 전환, 상태 필터, 명칭 검색, 로그인/임시저장/비밀번호 재인증 후 확정, 모의 수행·기록 추가의 기존 경로 유지.
- `localStorage` 스키마 버전 **2**, 저장 키 `nursing-order-demo-v02` **변경 없음**. 기존 시드 데이터 4명·38종·16건 유지.

## 검증 제한
- Chromium Playwright는 네트워크/파일 탐색 환경 제약으로 **HTML/CSS/JS를 별도 페이지에 삽입**한 브라우저 상호작용 검사. 실제 HTTP 주소/디바이스/브라우저 종료→재시작 후 지속성은 검사하지 않음.
- 실제 nU 및 병원 업무 상태, 환자 안전, 로그인 보안, 임상 권한/동등성은 검증하지 않음.
- MI​CU 프로그램과 **코드/데이터 연동은 하지 않았음**; 통합 위험 검토만 문서화.
- UI는 교체 가능한 임시 화면이며 사용성 시험·사용자 직접 테스트는 **추후 MVP 기능이 안정화되면 실시**.
