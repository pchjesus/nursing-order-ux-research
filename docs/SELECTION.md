# MVP 간호활동 후보 선정 (38건)

- 원본 315건 중 ACT 38건을 의미가 유사하지만 구별해야 할 항목(드레싱 5종, 흡인 위치별 3종, 도뇨관/말초·중심정맥 관리, 관찰/수행 혼동 등)과 4명 환자 병력에 맞춰 선정.
- ACT를 벗어나는 FOLLOW/MAT는 처방 대상에 포함하지 않음. 유형 혼동 사례로만 활용.
- 항목명/코드는 기존 합성 목록을 재사용; 어떤 항목도 nU에서 실제 처방 가능하다고 단정하지 않음.
- 상세 적용 조건, 진료지침 및 실제 병원 업무에 대한 임상 검증은 수행하지 않음.
