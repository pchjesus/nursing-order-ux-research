## 데이터 안전 기준
- 실제 nU 처방코드나 병원 내부 자료가 아니라 `SIM-` 접두어의 합성 후보 항목 315개를 사용함.
- `ACT`(간호활동), `FOLLOW`(연계 수행), `MAT`(물품)을 구분함.
- 원본 처방·수행·기록 식별성을 유지하고 임상 검증 전에는 실제 진료 또는 공식 기록에 사용하지 않음.
- 환자정보, 자격증명, 병원 비공개 자료를 커밋하지 않음.

## 앞으로의 버전 관리
1. 작업 전 원격 `main`과 파일 변경 사항, 마지막 커밋을 확인한다.
2. 새로운 기능·문서를 수정할 때 영향 범위를 확인하고 필요한 검증을 한다.
3. 기존 콘텐츠를 보존하고 수정한 파일만 커밋한다. 확정되지 않은 UX 선택은 사용자 결정 후 반영한다.
4. 원격 `main`의 업로드 결과, 브랜치 및 Private 설정을 실제로 확인한다.
5. 주요 변경 내용과 미검증 사항을 `DEVLOG.md`에 기록한다.
