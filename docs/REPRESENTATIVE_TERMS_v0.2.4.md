# v0.2.4 — 대표 용어 중심 제품·재료 카테고리

작성: 2026-10-10 · **간호처방 프로젝트 단독 패치 / 합성 교육용 시뮬레이션**

## 사용자 요구 반영

- 제조사 모델명과 제품 규격을 처방 선택 UI의 기본 표시명으로 나열하지 않는다.
- **듀오덤, 비지블 드레싱, 도지 플로우**처럼 알아보기 쉬운 대표 용어를 우선 표시한다.
- 관련 분야와 재료 성격에 따라 카테고리화하여 선택·검색·조회한다.
- 같은 용어라도 본래 제품/기구 유형이 다른 경우는 임의로 동일 품목으로 합치지 않는다.

## 자료/용어 구분

- **대표 용어**: UI에서 빠르게 찾아보기 위한 교육용 인지 이름 또는 일반 품목군 별칭. 개별 제조사의 정식 제품명 또는 의료기관 표준코드가 아니다.
- **카테고리**: 드레싱(하이드로콜로이드·투명필름·폼), 피부보호, 중력식·유량조절기형·펌프 전용 수액세트, 정맥관 보조품, 흡인·기도, 모니터링, 도뇨, 체위보조 등 총 12개 *표시 분류*. 처방 가능한 ACT의 10개 임상 목적 카테고리와는 별도의 축이다.
- **원본 제품 참조**: v0.2.3의 `SIM-PRD-*` 및 `SIM-GEN-*` **18개 ID와 이름·제품군·제조사 참고 URL**을 변경하지 않는다. 단지 `displayName`, `variant`, `categoryId`, `aliases`를 메모리상 메타데이터로 추가한다.
- **비지블 드레싱**: 사용자가 제안한 **현장식 대표 표현을 투명필름 카테고리의 검색·표시용 명칭으로 사용**한다. 상표/제조사명 또는 기존 Tegaderm 제품과의 동등성을 검증했다는 의미가 아니며 실제 제품 사용/호환 판정에 사용할 수 없다.
- **도지 플로우**: 일반적인 **유량조절기형 수액세트**를 찾기 위한 별칭. 제조사 B. Braun *Dosifix*와 동일 물품이라는 뜻이 아니다.
- **듀오덤**: 하이드로콜로이드 제품군의 인지 표현. 과거 참조 ID가 2개인 것은 유지하고, 화면에서는 **얇은형/일반형**을 구분해 잘못된 동일품 취급을 예방한다.

## 사용 흐름

1. **간호활동 ACT 선택** → 해당 활동에 *관련성이 있는* 재료 카테고리만 표시.
2. **재료 카테고리 선택(선택 사항)** → 하위 제품 드롭다운에 해당 분류만 표시. 전체 카테고리를 유지하면 `optgroup`으로 분류별 항목이 표시됨.
3. **대표 명칭 선택(선택 사항)** → 기존 제품 ID가 **개별 처방의 `details.productId`**에 저장되며 새 처방의 `details.productName`에는 대표 표현을 스냅샷으로 저장.
4. 부위·목적·빈도·방법 및 환자 ID, 작성자/확인자, 기존 주문 ID는 변경하지 않음.
5. **기존 v0.2.3 주문**은 `details.productName` 원본 스냅샷을 그대로 유지하며, 화면에서는 해당 ID의 대표 용어로 변환해 조회. 삭제된/알 수 없는 제품 ID는 저장된 원본명을 그대로 표시.
6. 방법/제품 카테고리 변경으로 제품 선택이 부적합해지면 **제품 선택을 자동 해제**하고, 이전 제품을 다른 카테고리로 옮기거나 새 ID로 자동 바꾸지 않음.

## 구현·위험·검증

- `app/activity-details.js`: 기존 18개 제품의 원본 필드를 유지하며 대표 용어/분류 메타데이터를 덧씌운 확장 Fixture 생성. 새 데이터 스키마·마이그레이션 불필요.
- `app/app.js`, `index.html`, `styles.css`: 카테고리 필터와 그룹 표시, 도움말, 대표 용어 조회.
- `app/domain.js`: 대표 용어 검색과 신규 저장 스냅샷 표시명. 기존 원본 `productId` 및 저장 키 `nursing-order-demo-v02`, `schema=2` 유지.
- `app/order-sheet-model.js`: Kardex/처방지에서 읽기 전용 대표 용어 표시.
- 제품 이름을 간략화해도 적응증·멸균 조건·재료 특성·펌프 세트 규격이 동일하다는 의미는 아님. 실제 사용을 위해서는 제품/기종/수량/크기/기관 규정 검증이 필수.
- 기존 ACT 42건(원본 315개 후보 전체 보호), 합성 환자 4명, 초기 처방 16건, PRN·MICU 저장소는 변경하지 않음.
