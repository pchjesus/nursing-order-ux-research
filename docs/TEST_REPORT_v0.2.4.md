# 간호처방 시뮬레이터 v0.2.4 — 개발자 검사 기록

작성: 2026-10-10 · 합성 데이터 전용 · 실제 임상 및 사용자 사용성 테스트 미수행

## 변경 영향
- 대표 제품·기구 용어 및 별도 재료 카테고리 12개, 선택적 카테고리 필터, 분류 `optgroup`, 대표 검색어와 기존 원본 제품명 검색 동시 지원.
- 과거 제품 스냅샷은 **저장된 원본명 그대로 보존**, 화면만 대표 용어로 표시. 신규 제품 저장 시 대표명 스냅샷 보존, 이전 ID 유지.
- 처방/수행/기록 개체, `schema=2`, 로컬 키, 42개 ACT, 4명 환자, 16건 합성 주문, 원본 315개 분류 자료 변경 없음.
- PRN/MICU 코드·저장소·공통 ID·통합 기능 변경 없음.

## 테스트하지 않았거나 주장하지 않는 것
- 실제 `http://localhost` 네트워크 접근, 사용자 PC/모바일 저장 수명, 다른 기기/브라우저 환경의 로컬 저장/복원.
- 사용성 시험, 실제 nU UX 동일성, 임상 용어 타당성, 제품 호환성, 실제 직원 계정/병원 데이터 연동.
- DOM 주입 테스트에서는 메모리로 대체한 localStorage를 사용했으므로 사용자의 실제 디스크 지속성을 증명하지 않음.

## 회귀 보호
- 원본 제품 ID `SIM-PRD-*`, `SIM-GEN-*` 18개 불변. `SIM-ACT-*` 42개 및 모든 개별 주문·수행·기록 ID 유지.
- 이전 v0.2.3 제품명 `productName` 저장값은 읽기 검증만 수행, 마이그레이션/삭제/자동 재매핑하지 않음.
- 알려지지 않은 제품 ID는 저장된 명칭을 그대로 보여주며 UI가 다른 품목으로 바꾸지 않음.
- '비지블 드레싱'은 교육용 일반 표현이므로 특정 제조사 제품과 임상적으로 동일하다는 의미로 사용 금지.
